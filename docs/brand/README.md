# Countersign brand

**The logo is Constellation:** the War Room's agents in pipeline order around a C, each wired to the amber
Countersign core, ending at the Policy Engine (the ice square). The C is the lock; the only way out is past
the Policy Engine.

| File | Use |
|---|---|
| `countersign-lockup-white.svg` / `.png` | Mark and wordmark on dark backgrounds |
| `countersign-lockup.svg` / `.png` | Mark and wordmark on light backgrounds |
| `countersign-mark.svg` | The mark alone, transparent |
| `countersign-icon.svg`, `countersign-icon-1024.png` | App icon (mark on an OLED rounded square) |
| `countersign-stacked.svg` | Mark, wordmark and tagline, for slides |
| `countersign-cover.png` | Devpost cover, 1500×1000 (3:2) |
| `favicon/` | `favicon.svg`, 16/32/48 px, Apple touch icon (180), 192 and 512 px; a heavier-stroke version of the mark that reads at small sizes |

**Colours,** one meaning each: amber `#f2b04c` is Countersign at work, ice `#7cc4f5` is code and the lock,
violet `#c3a6ff` is the owner, green `#5bd69b` is money cleared, red `#ff6b4a` is a refusal, on black `#000000`
with white `#fafafa` ink. **Type:** Geist 600 for the wordmark (outlined in the SVGs, so they need no font).
The app's full design system is in [`DESIGN.md`](../../DESIGN.md).
